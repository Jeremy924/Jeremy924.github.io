Free42

Free42 is an RPN calculator software that mimics the HP 42. Because it mimics the HP 42, the official HP 42 manual can be used as the manual for Free42.
Free42 is open source, so the code and liscense can be found on GitHub here.

Downloads for Free42

  • Development Version 0.0.1 (compatible with firmware: 0.0.5) Download

    This version is only for development
    This version can perform basic operations. Cannot be turned off through software, must be unplugged. Cannot save state when power is off. Slow response time from buttons sometimes. Clock frequency is not dynamic. No annunciators. Compiled for debugging, not optimized.

Goals

  • 1. Get all the functionality of Free42 to work on the calculator.
  • 2. Design user-friendly installer to simplify installing code.
  • 3. Optimize the software to minimize power consumption.
