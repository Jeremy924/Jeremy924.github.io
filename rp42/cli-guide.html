RP-42 CLI Guide

Downloading RP-42 CLI

The latest CLI can be downloaded from here: v. 0.3

Using the CLI

Commands can be called by running "python RP42CLI.py {command name}" where command name is from the list below.

Command Name Description
terminal Accesses the RP-42 terminal over the serial com port
news* Gets the latest news about RP-42 updates.
download Downloads application binaries, but does not install them
install Installs application binaries
upgrade Upgrades RP-42 firmware
updatable* Checks current firmware and apps for updates. Requires v. 0.11 or later firmware.
legacy-upgrade Upgrades from firmware less than 0.4 to the latest firmware. Also may be used to repair the device

*new in CLI v. 0.3
