Updating to the latest Free42

Published on August 13, 2025 by Jeremy Leicht

The process listed below is only necessary 1 time while updating from the old version to the latest. In the future, you will be able to simply run RP42CLI upgrade to upgrade the firmware to the latest, and RP42CLI install Free42 to update Free42 to the latest free42.

Because firmware 0.12 switches from using FRW to using unlock and lock commands, you will need to use the old installer to upgrade the firmware to the latest firmware.

The old installer can be found here.

Simply download the installer, then run python RP42CLI-0.2.py upgrade

This will automatically upgrade your firmware to 0.12.

After that, you need to use the new firmware to install the latest free42.

The new installer can be found here.

The new installer uses app lists to track app updates, however the older installer does not update the app list, so the new installer will not know what is current is installed.

To fix this, just run python RP42CLI-0.3.py upgrade again. This will run through the normal upgrade process and update the app list.

Now, to install Free42, simply run python RP42CLI-0.3.py install Free42. This will automatically check what firmware is installed and download the latest version available for that firmware.
