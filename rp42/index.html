What is RP-42

RP-42 is a low cost calculator primarily designed to run Free42.

Features

  • Full functionality of the HP42
  • 8MB of flash memory to store Free42 programs and data and other applications

Development Status

Software Status

Version 0.0.1 was released on 1/22/2025. It can do basic operations, however it is still missing many features required for Free42.

Hardware Status

Version 0.0.5-b is the latest hardware version. It is fully functional, however there are a few minor problems. The pin used as input from the power button does not support wake-up from powerdown on the microcontroller which means the lowest power mode possible is STOP2. The reset and BOOT0 buttons do not match the pads on the PCB which means they cannot be used.
