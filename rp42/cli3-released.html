Command Line Interface

Published on August 7, 2025

The RP42CLI requires Python and Pyserial to run. The CLI is a single file with no configuration files, so RP42CLI.py can be downloaded and executed without any additional installation.

Connecting RP-42 to your computer

The following process is for connecting RP-42 with firmware <=0.11 to your computer.

  1. Disconnect power including the battery.
  2. Hold down the top left button (sum+) and while holding down the button connect the USB from your computer to RP-42.
  3. RP42CLI should automatically identify your device, but if not, you may need to manually specify a port using the --port parameter.

Commands

Running RP42CLI without any arguments will cause it to print the command list. Additionally, at the top it will display information about any updates avaiable for the CLI.

install {app-name} [--file={file-name}] - Downloads and installs the given app. If a file is specified instead of an app name, then that file will be installed. Note that installing from a file will not update the app list, which may cause issues with app version tracking.

$ RP42CLI install Free42

download {app-name} - Downloads but does not install the given app. The file will be saved in the current directory.

$ RP42CLI download Free42

upgrade - Upgrades RP-42 to the latest firmware. Disconnecting RP-42 while upgrading firmware may break the calculator.

$ RP42CLI upgrade

terminal - Connects to the RP-42 terminal. This can be used to configure the calculator by adjusting parameters such as button debounce time. 

$ RP42CLI terminal

updatable - Checks the current versions of all installed apps and firmware and compares them to the latest versions available online. This is new for CLI 0.3 and is only compatible with firmware >= 0.11. 

$ RP42CLI updatable

news - Gets the latest information about RP-42. This is new to CLI 0.3. 

$ RP42CLI news
