RP-42 OS

Currently, the only task that the RP-42 OS frontend performs is selecting between different programs to execute.



OS 0.0.5 (latest version)

  • RP-42 OS 0.0.5 can select between executing a hardware test, COM port interface, or the current application on the flash. 0.0.5 does not support FAT FS, so only one application can be stored on the flash, with its reset vector stored in the first address in the flash.

    The program is selected by holding down a specific key while powering on the calculator.
    • Default operation Execute what is stored in flash.
      0.0.5 does not verify that this is a valid program.
    • Top left key held down: Start the COM port iterface. COM port interface
    • Second key from top left held down: start hardware test.
      The hardware test can be used to test the screen and the buttons. Whenever a key is pressed, the key id corresponding to that key will be displayed on the screen. Whenever a key is released, 255 will be displayed on the screen.
