RP-42 Update 4/1/26
Added pre-release version with printout to screen. To view the printout, press and hold button 3 (sqrt). Holding it briefly will show the history and then hide it when you release. Push and hold for a few seconds to make the history stay up. Once the history is up, use the ⮝ and ⮟ keys to go back in history. Since the printout is 143 pixels wide and the screen is 132 pixels wide, it may be necessary to use the shift button to shift the screen left to view the rest of the printout. The printout will store 50 frames before erasing the oldest data (this number may be adjustable in the stable release). Click exit to leave the printout. 

*Note that in battery mode, the printout will take a noticeable amount of time, so it is not recommended to use the trace mode on battery power. This may be fixed in a future update if possible.*




RP-42 Update 9/13/25
Free42 v. 0.12 will be released today. The major feature for this update is importing programs using the "load program" item 
in the menu. Exporting programs was disabled due to a bug, but will be fixed in the next update. Use the command
"RP42CLI install Free42" to update Free42 to the latest version.

Firmware v. 0.17 will be released today as well. This includes bug fixes and the underscore and dash characters were added to
the font. Use the command "RP42CLI upgrade" to install the latest firmware.
