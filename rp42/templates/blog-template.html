New Update: Firmware v4.13.0 is Here!

Published on August 7, 2025 by Jeremy Leicht

We're excited to announce the release of firmware version 4.13.0 for the RP-42. This update brings a host of performance improvements, bug fixes, and a few new features requested by the community. Thank you for your continued feedback!

What's New?

This version focuses on stability and enhancing the user experience. Here are the key highlights:

  • Improved Battery Life: We've optimized power consumption, resulting in an average of 15% longer battery life during typical use.
  • Faster Boot Times: The calculator now starts up approximately 2 seconds faster.
  • New Math Function: Added the FACTORIAL() function directly accessible from the main menu.
  • USB File System Fix: Resolved a rare issue where the device would not be recognized when plugged into certain USB 3.0 hubs.

Using the New Function

To use the new factorial function, you can access it via the command line interface or directly in your programs. Here's a quick example:

# Calculate 5!
5
FACTORIAL
# Result: 120

We believe these updates will make the RP-42 even more reliable and enjoyable to use. To get the latest firmware, head over to the Software page and use the Universal CLI Tool to update your device.
