Making System Calls

The first step to making a System Call is to load the opcode and arguments into the SYS_CALL_DATA structure. The structure contains 3 arguments.

The first is the 16-bit op code which is from the chart below.

The second is the argument pointer. This may be treated as a pointer to the arguments or the argument itself, depending on what is listed in the table. For example, for the DRAW_LCD operation, the void* will be cast to a uint8_t* and dereferenced to get the data to draw. For the PUSH_KEY operation, the void* will be cast to a uint8_t and used as the argument for the function.

The third argument for a system call is the return value. This value does not need to be set to anything by the calling code, but after performing the system call, it may contain the return value from the operation.
The table below summarizes the SYS_CALL_DATA.

System Call Data Structure
Address Size Name Data type
0x20000000 2 bytes Op code uint16_t
0x20000002 4 bytes Arguments void*
0x20000006 4 bytes Return value uint32_t

After loading the data into the SYS_CALL_DATA structure, the system call can be executed with the following assembly instruction.

__asm("SVC #0");

Setting up project to make API calls

First, the linker file must be updated to include the SYS_CALL_DATA structure so that it can always be found in the same spot. To do that, add the following line in the memory definitions.

SYS_CALL_DATA (rw) : ORIGIN = 0x20000000, LENGTH = 10
This will allocate 10 bytes that will always be at 0x20000000.

To ensure that the linker loads the .SYS_CALL_DATA objects into this section, the following lines must be added to the SECTIONS section.
.SYS_CALL_DATA (NOLOAD) :
{
. = ALIGN(4);
*(.SYS_CALL_DATA)
. = ALIGN(4);
} >SYS_CALL_DATA

Next, define a structure to contain all the data for sys calls.
#pragma pack(1)
typedef struct {
uint16_t command;
void* args;
uint32_t result;
} SystemCallData;
#pragma pack()

Define a object to pass arguments for system calls. Make sure that it is placed in the SYS_CALL_DATA section by using attribute section(".SYS_CALL_DATA").
SystemCallData __attribute__((section(".SYS_CALL_DATA"))) systemCallData;

Example System call

Using system call to draw to LCD
systemCallData.args = frame; // the frame array contains the bytes to draw to the LCD
systemCallData.command = 0x0012; // 0x0012 = DRAW_LCD
__asm__("SVC #0"); // perform the sys call
// DRAW_LCD has no return value, so nothing is needed afterward
