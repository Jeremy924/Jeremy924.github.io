Error 000: Corrupt File System

Error 000 means the calculator was unable to read information about the file system. There are a few possible reasons for this.

File system not formatted

Try connecting your calculator in USB mode (hold top left button and apply power). Check your file explorer to see if it is listed. If it is listed, check to see if you can access the files on the calculator.
If your file explorer says the file system is not formatted, then format it using your computer.

Low battery power

If your battery is low, then the flash memory may not work correctly. Try using it on USB power or replace the battery.
