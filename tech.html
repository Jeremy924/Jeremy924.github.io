RP-42

https://github.com/Jeremy924/rp42-hardware

RP-42 is a scientific reverse polish notation calculator modeled after the HP42. RP-42 uses custom hardware with custom firmware to run an open source clone of the HP42, Free42. RP-42 uses a custom PCB featuring a STM32L475 microcontroller, 8MB flash storage, 132x32 low power LCD screen, and dual power (usb or battery).

Features

  • 8MB QSPI Flash formatted as an Fat32 filesystem with support for execution directly from the flash (XIP) with 80MHz QSPI communication.
  • Low power consumption at 600uA in standby, 2mA when running, and 30uA when off when on battery.
  • Micro USB FS port for virtual serial communication, file system access and power. CPU will automatically increase clock to 80MHz when on USB power for improved performance.
  • 132x32 reflective STN LCD display for low power consumption and ease of viewing.
  • SWD debug port for debugging user applications and firmware.
  • Altium

  • PCB Testing
  • Serial Communication
  • STM32

RP-42 Firmware

https://github.com/Jeremy924/rp42-firmware

The operating system for RP-42 is RP-OS, which is a custom operating system designed for the RP-42. It includes support for accessing the fat filesystem, drawing to the screen, reading from the keyboard, controlling timers, and a terminal interface over USB. The OS controls all IO components so that applications are hardware independent.

Features

  • Fat32 Filesystem interface allows applications to access the 8Mb flash or standard input/output (through the com port) using builtin C/C++ file controls.
  • LCD drawing commands for drawing text or raw pixel data to the screen including text with a custom font.
  • Keyboard scan commands for waiting for user input or scanning the keyboard. RP-OS internally has a queue so that no key press is missed.
  • Built-in custom timer system with 1ms precision. User applications can register or unregister custom timer callbacks with a single function call.
  • Terminal interface over USB for configuring the calculator or reading/writing to standard out/in. Supports basic file commands like ls, cd, touch, etc. and other configuration commands.

  • C++
  • STM32
  • Serial Communication

RP-42 Application

The main application that RP-42 was designed to run is Free42, which is an open source clone of the HP42. Free42 for RP-42 supports saving and loading multiple states allowing the user to switch between multiple calculator states. Free42 for RP-42 saves states to the file system which can be accessed by connecting it to a computer over USB which allows users to upload states from their PC to the calculator.

Features

  • All the features of the original HP42.
  • Saving and loading states allows the user to switch between multiple configurations of the calculator. Uses the file explorer built into RP-OS.
  • Configuration menu for configuring Free42 such as setting the auto-off time.
  • C++

RP42 CLI

RP42CLI is a command line interface for configuring RP-42, installing apps, and upgrading the firmware.

Features

  • Downloads and installs apps with a single command. For example: RP42CLI install Free42 would install Free42.
  • Download and upgrade firmware with a single command. No special operations have to be performed to install new firmware, all the user has to do is switch to install mode in the menu. RP42CLI upgrade would automatically download and install the latest published firmware.
  • Made with a single python script to further simplify configuring the calculator.
  • Builtin RP-42 terminal access so there is no need to install a tool like PuTTY to configure the calculator.
  • Updatable command which automatically checks the currently installed app/firmware versions versus the latest published versions.
  • Python
